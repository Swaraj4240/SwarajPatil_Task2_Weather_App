# Weather App

## Description

Weather App is a Python-based command-line application that fetches and displays real-time weather information for any city using the OpenWeatherMap API. The application provides current temperature, humidity, and weather conditions in a simple and user-friendly format.

## Features

- Fetches real-time weather data
- Displays current temperature in Celsius
- Shows humidity percentage
- Displays weather conditions
- Uses OpenWeatherMap API
- Simple command-line interface
- Error handling for invalid city names

## Technologies Used

- Python 3
- Requests Library
- OpenWeatherMap API

## Prerequisites

Before running the project, ensure you have:

- Python 3 installed
- Internet connection
- OpenWeatherMap API Key

## Installation

Install the required package:

```bash
pip install requests
```

## How to Run

1. Open Command Prompt, PowerShell, or VS Code Terminal.
2. Navigate to the project folder.
3. Run the following command:

```bash
py weather_app.py
```

4. Enter a city name when prompted.

Note: Replace "YOUR_API_KEY" in weather_app.py with your own OpenWeatherMap API key before running the application.
